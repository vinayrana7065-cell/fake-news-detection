TRUTHLENS - AI-BASED FAKE NEWS DETECTION (CLASSROOM PROTOTYPE)

Run locally:
1) Install Python 3.
2) Open a terminal in this folder.
3) Run: python -m pip install -r requirements.txt
4) Run: python app.py
5) Open http://127.0.0.1:5000 in your browser.

IMPORTANT:
This prototype uses simple pattern-based scoring, not a trained machine-learning
model and not source/claim verification. Scores are illustrative. Do not treat
its output as a factual determination.

Files:
app.py - Flask server and demo analysis logic
 templates/index.html - webpage
 static/style.css - styling
